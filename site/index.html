01 · What's inside

The material, not a filter.

Liquid Glass is more than blur. It bends light, catches highlights and reacts to touch. Every piece here does the same.

ButtonTab BarToggleSliderToolbarDockPopoverNav Bar ButtonTab BarToggleSliderToolbarDockPopoverNav Bar
SheetSearchSegmentedSidebarToastCardIcon Button SheetSearchSegmentedSidebarToastCardIcon Button

15 chrome-layer components

Bars, controls and overlays. The parts of an interface that float above content, which is the only place glass belongs.

Real refraction

SVG displacement maps bend the backdrop like a lens, with clean fallbacks outside Chromium.

Spring physics

Native CSS linear() springs. Selections stretch, overshoot and settle like iOS.

Built for your agent

One skill, six agents. Your AI writes glass that follows the rules instead of guessing.

prefers-reduced-motionStatic
prefers-contrast: moreHard edges

Accessible by default

Every component ships with fallbacks for transparency, motion, contrast and forced colors, plus WCAG AA text.

<!-- that's it --> <nav class="glass-tabs"> <button role="tab"> Home </button> </nav>

Zero dependencies

Copy a CSS file, add a class, ship it. No framework, no build step.
